美式生活館 (American Life Hub) - 16 單元獨立 HTML 檔案
------------------------------------------------------
包含檔案：
unit1.html  ~ unit16.html (共 16 個獨立、無依賴的單元學習網頁)

特色：
1. 包含高頻核心句型 (Core Sentences) 與完整中文翻譯
2. 包含真實情境對話 (Dialogue)
3. 內建瀏覽器原生語音合成發音 (Web Speech API)，無需外部音檔即可點擊朗讀
4. 包含上一單元、下一單元與回首頁之快速導覽

使用方式：
直接將 unit1.html ～ unit16.html 放入您的 GitHub 專案目錄（例如 jenlin2002.github.io 或 daily_life_listening），即可在首頁直接以 <a href="unit1.html">連結各單元！

Android 手機用 Chrome

  1. 掃描後，點跳出的網址打開頁面（掃描只會打開網頁，要自己按下面的安裝）
  2. 按右上角的 ⋮（三個點）
  3. 選「安裝應用程式」
    （不要選「捷徑」）
  4. 按「安裝」，桌面就會出現「B&M 學習」

iPhone / iPad一定要用 Safari

  1. 掃描只會打開網頁，不會自動安裝。要用 Safari（藍色指南針）打開網址；在 LINE 或相機小視窗裡打開的話，先選「在 Safari 開啟」
  2. 按「分享」（方框加向上箭頭）：iPhone 在畫面下方，iPad 在網址列右邊（上方）
  3. 選單往下滑，選「加入主畫面」
  4. 按右上角「新增」，主畫面就會出現「B&M 學習」

第一次打開

  1. 出現「你是誰？」，選自己的名字，再輸入你的 PIN。
  2. 入口有「英文測驗系統」和「美式生活館」兩個按鈕，登入一次兩邊都通用。
  3. iPhone：從主畫面圖示打開，要重新登入一次（和 Safari 的登入是分開的）。
  4. 不是 BRANDEN 或 MELISSA？請家長先幫你建立帳號，再用「其他帳號登入」。
點數存摺、測驗成績都存在雲端，換手機也不會不見。
